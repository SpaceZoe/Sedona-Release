# 🌿 Sedona Release — A Gentle Releasing Web App

This is my first self-built web project, inspired by the book *The Sedona Method*.  
After starting to practice small emotional releases in my own life, I wanted to build a minimal, calm digital tool to help guide that same process.

---

## 🧠 Project Story

I study **Data Science**, which is usually logical and structured, but recently I’ve been exploring something softer, emotional awareness and letting go.  

1. Used **GPT-5** to generate the first React + Tailwind prototype.  
2. Iteratively refined the design and transitions through several rebuilds.  
3. Initialized a **Vite React** project locally and set up **Tailwind CSS**.  
4. Deployed the final version to **Vercel** for an accessible online experience.

It’s not just a website, and it’s my small experiment in turning self-reflection into interactive design.

---

## 🧩 Tech Stack

- ⚛️ **React 18**
- 🎨 **TailwindCSS 3**
- ⚡ **Vite 5**
- ☁️ **Vercel Deployment**
- 🤖 **GPT-5 Assisted Code Generation**

---

## 🌈 Features

- Soft typewriter animation for gentle guidance  
- Simple step-by-step releasing flow  
- Responsive layout for mobile and desktop  
- Background visuals inspired by sunrise calmness  
- Fully hosted on Vercel with continuous deployment

This project started from a feeling, not a plan.  
I just wanted to make something quiet, warm, and personal, where is a space for letting go.
